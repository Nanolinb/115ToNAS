# 🎬 115 影库（115 Media Hub）

部署在 QNAP NAS 上的私人媒体中心，**双通道设计**：

- **观影端** `http://NAS的IP:8115/` — 电视/投影仪/iPad 直接用：海报墙选片、点一下就播，**默认免密**（可选设独立观影密码），就像一个装在电视上的 App
- **管理端** `http://NAS的IP:8115/admin` — 手机/PC 上的独立控制面板：115 扫码登录、网盘浏览下载、下载队列、NAS 目录配置、密钥管理，**独立管理密码**

影片解码全部交给播放设备（NAS 不转码），观影端只读影片库 + 流式播放，碰不到 115 账号和任何设置。

## 功能

- **115 网盘**（管理端）：手机 115 App 扫码登录；浏览/搜索网盘，勾选文件或整个文件夹加入下载队列
- **下载器**（管理端）：串行下载、断点续传、可限速、暂停/继续/取消、批量暂停/启动/清空记录、批量改存储位置（.part 一并搬移）、批量删除（含临时文件）；按 pickcode 持久记录下载历史，重复文件自动跳过（清空记录后依然有效）
- **文件管理**（管理端）：浏览 NAS 媒体目录，新建文件夹、重命名、移动、删除，自动同步媒体库路径
- **媒体库**：自动扫描电影/剧集目录，解析文件名，TMDB 刮削海报/简介/评分/题材
- **字幕**：优先识别视频旁已有字幕（同名前缀 + 去发布标签模糊匹配，剧集按集数对齐）；可配置射手网(伪) assrt.net token 自动下载中文字幕（.zh.srt）
- **观影端海报墙**：关键字搜索 + 类型/题材/年份过滤，剧集自动按季分组，即点即播
- **播放**：HTML5 流式播放（支持拖动进度条），浏览器/设备直接解码 avi、mp4、mkv 等；也可以复制直链给极米/Infuse 等播放器
- **目录管理**（管理端）：网页里即可浏览 NAS 目录、新建文件夹、指定电影/剧集/下载目录
- **双通道鉴权**：管理端独立密码；观影端默认免密、可选观影密码

## 资源占用（为 QNAP X-86设备 8G内存 优化）

- 单进程单 worker，常规内存 100–250 MB（compose 已限制 512 MB / 1 核）
- 不转码、不建索引缩略图视频，只做文件流式传输
- 串行下载（同时只下 1 个），256 KB 分块写入

## 部署步骤（QNAP Container Station）

### 1. 准备目录

File Station 里确认共享文件夹 `Multimedia/115Download` 存在（不存在就新建）。
建议里面建三个子文件夹：`movies`、`tv`、`downloads`（不建也行，部署后在网页里建）。

### 2. 上传项目

把整个 `115-media-hub` 文件夹上传到 NAS，例如放到
`/share/Container/115-media-hub`（用 File Station 上传 zip 后解压即可）。

### 3. 检查挂载路径

`docker-compose.yml` 里默认是：

```yaml
- /share/Multimedia/115Download:/media
```

如果你的卷名不同（如 `CACHEDEV2_DATA`），在 File Station 右键文件夹 → 属性里看真实路径，改成对应路径。**只需改冒号左边。**

### 4. 创建应用

Container Station → 「应用程序」→「创建」→ 粘贴 `docker-compose.yml` 的内容 →
（第一次创建时把 `build: .` 保留，Container Station 会在应用程序目录构建镜像）

也可以用 SSH：

```bash
cd /share/Container/115-media-hub
docker compose up -d --build
```

### 5. 首次配置（2 分钟）

1. 手机或电脑浏览器打开管理端 `http://NAS的IP:8115/admin`，设置**管理密码**
2. 「设置」页：
   - 填入 TMDB API Key（[免费申请](https://www.themoviedb.org/settings/api)，选 Developer）
   - 填入 assrt.net 字幕 Token（[注册后获取](https://assrt.net/usercp)，可选）
   - 用「浏览」按钮确认/新建电影、剧集、下载目录
   - 可选：设置「观影页密码」（不设则电视/投影仪免密直接看）
3. 「115 网盘」页 → 获取二维码 → 手机 115 App 扫码登录
4. 勾选网盘里的影片 → 加入下载 → 下载完成自动刮削进媒体库

### 6. 各设备访问

| 设备 | 方式 |
|---|---|
| 智能电视 / 智能投影 / iPad（观影） | 浏览器打开 `http://NAS的IP:8115/` 即选即播，**无需登录**；播放不了的格式点「复制直链」粘贴到设备本地播放器 |
| 手机 / PC（管理） | 浏览器打开 `http://NAS的IP:8115/admin`，管理密码登录后可指挥 115 下载、改设置 |
| 外网（Tailscale） | 手机和 NAS 都装 Tailscale，用 `http://100.x.x.x:8115` 和 `/admin` 访问，无需公网暴露 |

> 观影端读取的是 NAS 提供的影片库 API，不是直接读数据库文件（多设备直读 SQLite 会损坏数据）。电视浏览器把观影页「添加到主屏幕」就是 App 体验；后续也可以再打一个安卓 TV 壳应用。

## 常见问题

**Q: 浏览器提示格式不支持？**
HTML5 播放能力取决于设备浏览器。mp4(H.264) 全兼容；mkv/avi 在 iPad Safari 上可能无声或无法播放，此时用「复制直链」到 Infuse/VLC/极米播放器，都能硬件解码。

**Q: 字幕没自动下？**
检查设置里的 assrt token；海报墙详情页可以手动点「搜索字幕」。视频旁边放同名字幕文件（如 `movie.zh.srt`）也会被自动识别。

**Q: 封面没刮到或刮错？**
确认 TMDB Key 已填；详情页点「重新匹配信息」，输入外文原名手动选正确的条目。

**Q: 115 登录失效？**
115 cookies 有时效，「115 网盘」页会回到扫码界面，重新扫一次即可（10 秒）。

**Q: 想限制下载速度以免影响其他容器？**
设置页填限速 KB/s；下载器本身就是串行的。

```

├── app/                # FastAPI 后端
│   ├── main.py         # 路由与流式播放
│   ├── cloud115.py     # 115 扫码登录/浏览/取直链
│   ├── downloader.py   # 下载队列（续传/限速/暂停）
│   ├── scanner.py      # 媒体库扫描
│   ├── tmdb_client.py  # 封面/元数据
│   └── subtitles.py    # 字幕搜刮
├── static/             # 前端（原生 JS，无构建）
├── Dockerfile
├── docker-compose.yml
└── config/             # 运行时生成：数据库、115 cookies、海报缓存
```
